# Johann Chiu Personal Portfolio

This project uses only HTML and CSS, as required by the assignment.

## Files
- index.html — website structure
- style.css — website styling
- assets/profile.jpg — your personal profile photo

## Before submitting
1. Put your own profile photo at `assets/profile.jpg`.
2. Replace `your-email@example.com` in `index.html` with your actual portfolio email.
3. Replace the `#` in the Capstone Project 1 link with your real project URL.
4. Test the site on desktop and mobile.
5. Upload the project folder to GitHub.

No JavaScript is used.
